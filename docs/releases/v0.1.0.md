## v0.1.0 (2026-03-16)

Initial release of the native Rust CUBRID client workspace.

### Compatibility

- The tagged workspace declares Rust 1.70 as its minimum toolchain. The original release reported tests on CUBRID 10.2, 11.0, 11.2 and 11.4; this is scoped historical evidence rather than a guarantee for all server configurations.

### Features

- Introduce the `cubrid-protocol` crate for CAS protocol frames and data encoding by @yeongseon
- Provide the synchronous `cubrid-client` interface for connections, queries and transactions by @yeongseon
- Add asynchronous Tokio integration through `cubrid-tokio` by @yeongseon
- Provide synchronous and asynchronous pooling through `cubrid-pool` by @yeongseon
- Support prepared operations, DSN parsing and configured isolation levels by @yeongseon
